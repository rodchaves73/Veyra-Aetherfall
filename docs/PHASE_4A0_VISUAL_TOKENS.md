# Fase 4A.0 | Dark Arcane Visual Tokens Foundation

## Objetivo

Criar a fundação estética explícita de Veyra: Aetherfall para as próximas subfases da Fase 4A, sem refazer telas e sem implementar sistemas de gameplay.

## Entregáveis

- Tokens CSS globais em `src/styles/veyra-theme.css`.
- Componentes/classes visuais em `src/styles/veyra-components.css`.
- Import global via `src/styles/globals.css`.
- Documentação do sistema visual em `docs/UI_VISUAL_SYSTEM.md`.

## Fora do escopo preservado

Não foram alterados Supabase, Edge Functions, migrations, auth, gacha logic, player bootstrap, game-state, dependências, Vite, Vercel, terminologia de token, Home, Summon, Heroes, Campaign ou Battle final.

## Segurança

A fase não introduz armazenamento persistente no navegador, cookies, credenciais server-side, tokens sensíveis, sessão secreta, gacha client-side ou reward client-side.

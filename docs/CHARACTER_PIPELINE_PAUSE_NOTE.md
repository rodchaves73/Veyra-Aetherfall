# Character Pipeline Pause Note

Stage 10 characters are intentionally excluded from this task and from the generated runtime asset extraction flow.

Future character work must follow these rules before any integration:

- Character Bible first.
- English labels only.
- Use the race name `Aetherborn`.
- Use the Aether element only for Divine/Mythic characters.
- Exactly one class per character.
- Exactly one element per character.
- Separate splash, front and back assets.
- Exact outfit, weapon, palette and silhouette consistency across all views.

Até a retomada formal de Stage 10, não integrar final heroes, character sprites, hero skill icons, hero ultimate icons ou hero battle FX.
